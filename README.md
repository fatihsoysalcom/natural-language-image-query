# Natural Language Image Query

This example demonstrates the core concept of querying visual data using natural language. It simulates a computer vision system by pre-defining image descriptions and then uses basic string matching to answer natural language queries about these 'images'. This illustrates how Natural Language Processing (NLP) can be combined with Computer Vision (CV) to interact with visual content.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
